# Actor store icons

Custom icons for the three public Apify Store actors, replacing Apify's
generic placeholder. Rationale: ApifyForge's SEO guide (cited in
`~/ops/routes/apify-actors/research/`) puts custom icons at ~2.3x the click
rate of the placeholder, and a consistent family lifts cross-actor discovery
inside our own portfolio.

## Family rules

- Identical rounded-square background, `#0B1220` (deep ink), corner radius
  18% of canvas, with a subtle radial vignette (`#141F33` -> `#0B1220`) --
  no other gradients, no drop shadows, no text.
- One accent colour per actor, plus white. No accent is reused across actors.
- One bold glyph per icon, stroke width >= 8% of canvas (~44px on the 512
  canvas), legible at 48px.
- Canvas 512x512 with ~12% padding on all sides before the glyph starts.

## Palette

| Actor | Accent | Hex | Glyph |
|---|---|---|---|
| app-review-monitor | amber | `#F59E0B` | speech bubble (white outline) with a filled star inside |
| fediverse-scraper | violet | `#8B5CF6` | five nodes joined in a pentagon, top node accented |
| tiktok-growth-monitor | teal | `#14B8A6` | rising 3-segment line ending in a play triangle |

Background ink `#0B1220` and vignette highlight `#141F33` are shared by all
three and are not counted as "accents."

## Files

- `<actor>.svg` -- hand-written source SVG (no fonts, no external assets), generated by `generate.py`.
- `<actor>-512.png`, `<actor>-128.png` -- rendered PNG exports (cairosvg).
- `contact-sheet.png` -- all three icons at 48px and 128px, on white and on dark, for a quick legibility check (built with Pillow).
- `generate.py` -- regenerates everything. Run `python3 generate.py` from this directory after any edit to the SVG-building logic.

## Judgment calls

- Stroke width was set to ~8.5% of canvas (a hair over the 8% floor) since
  the review-monitor bubble and the fediverse pentagon edges both read
  cleaner slightly thicker.
- The fediverse pentagon draws only the 5 outer edges (not the diagonals) --
  a complete graph would have muddied at 48px. Node rings get a thin ink
  stroke so the connecting edges appear to pass behind each node.
- The tiktok-growth line has one small dip in the middle (not perfectly
  monotonic) to read as an actual growth chart rather than a straight
  diagonal; the play triangle is rotated to match the final segment's angle.

## Upload path (manual -- console-only, API can't set actor icons)

1. Apify Console -> **Actors** -> open the actor (`astraedus/<name>`).
2. **Settings** (or **Publication** on published actors) tab.
3. Find the actor icon / image uploader, upload `<actor>-512.png`.
4. Save, then confirm the new icon shows on the actor's public Store page
   (`apify.com/astraedus/<name>`) and in the Console actor list.
